# 🤖 Module 4 – Analyse Prédictive (Classification)
## 📖 Présentation
Ce module est consacré à la construction et à l'évaluation de modèles de **Machine Learning** afin de prédire le succès de l'atterrissage du premier étage des lanceurs **Falcon 9 de SpaceX**.
Après les étapes de collecte, d'exploration et de visualisation des données, ce module met en œuvre plusieurs algorithmes de classification pour résoudre un problème de prédiction binaire.
---
# 🎯 Objectifs
Les objectifs de ce module sont les suivants :
- Préparer les données pour l'apprentissage automatique.
- Séparer les données en ensembles d'entraînement et de test.
- Entraîner plusieurs modèles de classification.
- Optimiser les hyperparamètres des modèles.
- Comparer les performances des différents algorithmes.
- Sélectionner le modèle offrant les meilleurs résultats.
---
# 📂 Contenu du module
## 🔹 Lab – Prédiction par Apprentissage Automatique
Ce laboratoire met en œuvre plusieurs algorithmes de Machine Learning afin de prédire le succès de l'atterrissage des lanceurs Falcon 9.
Les principales étapes réalisées sont :
- préparation des variables explicatives et de la variable cible ;
- division du jeu de données en ensembles d'entraînement et de test ;
- entraînement de plusieurs modèles de classification ;
- optimisation des hyperparamètres avec Grid Search ;
- évaluation et comparaison des performances des modèles.
**Algorithmes étudiés**
- Régression Logistique
- Support Vector Machine (SVM)
- Arbre de Décision
- K-Nearest Neighbors (KNN)
