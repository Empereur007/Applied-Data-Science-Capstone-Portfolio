# 📥 Module 1 – Collecte des données (Data Collection)
## 📖 Présentation
Ce premier module du cours **Applied Data Science Capstone** est consacré à la **collecte des données** nécessaires au projet d'analyse des lancements de SpaceX.
L'objectif est d'apprendre à récupérer des données provenant de différentes sources afin de constituer un jeu de données exploitable pour les étapes suivantes du projet.
---
## 🎯 Objectifs pédagogiques
Au cours de ce module, j'ai appris à :
- Collecter des données à partir d'une API REST.
- Extraire des données depuis une page Web (Web Scraping).
- Manipuler les données avec Pandas.
- Nettoyer et structurer les données collectées.
- Préparer un jeu de données pour les analyses futures.
---
## 📂 Contenu du module
### 🔹 Lab 1 – Collecte de données via une API
Dans ce laboratoire, les données des lancements de SpaceX sont récupérées grâce à l'API publique de SpaceX.
**Compétences développées :**
- Utilisation de la bibliothèque `requests`
- Consommation d'une API REST
- Manipulation de données JSON
- Création d'un DataFrame avec Pandas
---
### 🔹 Lab 2 – Collecte de données par Web Scraping
Ce laboratoire présente les techniques d'extraction d'informations directement depuis une page Web.
**Compétences développées :**
- Utilisation de BeautifulSoup
- Analyse du code HTML
- Extraction d'informations utiles
- Conversion des données en DataFrame
---
### 🔹 Lab 3 – Fusion et préparation des données
Le troisième laboratoire consiste à préparer les données collectées pour les prochaines étapes du projet.
**Compétences développées :**
- Nettoyage des données
- Gestion des valeurs manquantes
- Transformation des variables
- Sauvegarde des données au format CSV
---
