# Applied-Data-Science-Capstone-Portfolio
Bienvenue dans ce dépôt GitHub regroupant l'ensemble des travaux réalisés dans le cadre du cours **Applied Data Science Capstone** du **IBM Data Science Professional Certificate** proposé sur Coursera.
Ce dépôt retrace toutes les étapes du projet de fin de formation, depuis la collecte des données jusqu'au développement d'un modèle de Machine Learning capable de prédire le succès de l'atterrissage du premier étage de la fusée **Falcon 9 de SpaceX**.
---
## Objectifs du projet
Au cours de cette formation, les objectifs étaient de :
- Collecter des données depuis une API REST.
- Extraire des données par Web Scraping.
- Nettoyer et préparer les données.
- Réaliser des analyses exploratoires.
- Concevoir des visualisations interactives.
- Développer un tableau de bord.
- Construire un modèle de Machine Learning.
- Prédire le succès de l'atterrissage du premier étage de Falcon 9.

# 🚀 Projet final
Le projet final consiste à développer un modèle permettant de prédire si le premier étage d'une fusée **Falcon 9** pourra être récupéré avec succès.
Les différentes étapes comprennent :
- Collecte des données
- Prétraitement
- Analyse exploratoire
- Visualisation interactive
- Développement d'un tableau de bord
- Entraînement de modèles de Machine Learning
- Évaluation des performances
