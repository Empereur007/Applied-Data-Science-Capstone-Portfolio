# 📊 Module 2 – Analyse Exploratoire des Données (AED)
## 📖 Présentation
Ce module est consacré à l'**Analyse Exploratoire des Données (AED)** du projet **SpaceX Falcon 9 Landing Prediction**.
À partir des données collectées et préparées lors du module précédent, plusieurs techniques d'analyse sont utilisées afin de mieux comprendre les caractéristiques des lancements et d'identifier les facteurs influençant le succès de l'atterrissage du premier étage de la fusée Falcon 9.
L'analyse est réalisée selon deux approches complémentaires :
- l'exploration des données avec **SQL** ;
- la visualisation des données avec **Python**.
---
# 🎯 Objectifs
Les principaux objectifs de ce module sont :
- Explorer les données grâce aux requêtes SQL.
- Réaliser des analyses statistiques descriptives.
- Étudier les relations entre les différentes variables.
- Produire des visualisations pour faciliter l'interprétation des données.
- Identifier les caractéristiques importantes pour la phase de modélisation.
---
# 📂 Contenu du module
## 🔹 Lab 1 – Analyse Exploratoire avec SQL
Dans ce laboratoire, les données sont explorées à l'aide de requêtes SQL.
Les travaux réalisés comprennent notamment :
- interrogation de la base de données ;
- filtrage des observations ;
- calcul de statistiques ;
- regroupement des données ;
- extraction d'informations pertinentes.
**Compétences développées**
- SQL
- SQLite
- Requêtes SELECT
- WHERE
- GROUP BY
- ORDER BY
- Fonctions d'agrégation
---
## 🔹 Lab 2 – Analyse Exploratoire avec Visualisation
Ce laboratoire est consacré à l'exploration visuelle du jeu de données.
Les analyses portent notamment sur :
- les relations entre les variables ;
- les distributions des données ;
- les tendances observées ;
- les graphiques permettant d'interpréter les résultats.
Les visualisations facilitent l'identification des variables susceptibles d'améliorer les performances du futur modèle de Machine Learning.
**Compétences développées**
- Pandas
- Matplotlib
- Seaborn
- Visualisation de données
- Analyse statistique
